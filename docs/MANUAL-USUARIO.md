# Manual do Usuário — BIOGREEN SYSTEM

> Linguagem simples, para qualquer pessoa da empresa — do chão de fábrica à diretoria. Este manual cresce a cada fase; hoje cobre o que já existe (Fase 0).

## Entrando no sistema

1. Acesse o endereço do sistema no navegador (ou instale como aplicativo no tablet — ver "Usar no tablet" abaixo).
2. Digite seu usuário e senha na tela de login.
3. Se for seu primeiro acesso, a senha inicial foi combinada com quem configurou seu usuário — troque assim que possível (a tela de troca de senha chega numa fase futura; por ora, peça para o time de TI/administrador atualizar).

## A tela principal — Painel da Empresa

Assim que você entra, vê o **Painel da Empresa**: um resumo rápido de como a empresa está indo hoje.

- **Caixa do dia** — quanto entrou menos quanto saiu do financeiro hoje.
- **Contas vencendo (7 dias)** — quantos boletos/títulos (a pagar ou a receber) vencem nos próximos 7 dias.
- **Pedidos em produção** — quantos pedidos de venda estão sendo fabricados agora.
- **Lotes com laudo pendente** — lotes produzidos que ainda não têm o Certificado de Análise (COA) pronto.
- **Visitas técnicas da semana** — quantas visitas de assistência técnica estão agendadas para os próximos 7 dias.

Abaixo, duas colunas:
- **Atividade recente** — o que foi feito no sistema recentemente (quem fez o quê).
- **Atalhos por setor** — um clique para ir direto a qualquer módulo que você tenha permissão de ver.

## Menu lateral (sidebar)

Do lado esquerdo fica o menu com os módulos do sistema — só aparecem os módulos que **você tem permissão para ver**. Se sentir falta de algum módulo, fale com quem administra o sistema para revisar sua permissão.

Clique na seta no rodapé do menu para recolher/expandir (útil em telas menores).

## Busca global (⌘K)

No topo da tela tem uma caixa de busca — clique nela ou aperte **⌘K** (Mac) / **Ctrl+K** (Windows) de qualquer lugar do sistema. Digite o nome de um cliente, produto, número de lote ou de nota fiscal e o sistema te leva direto pra lá. Só aparecem resultados dos módulos que você tem permissão de ver.

## Modo claro/escuro

O ícone de sol/lua no topo alterna entre os dois modos. O sistema lembra sua escolha da próxima vez que você entrar, nesse mesmo navegador.

## Sair

Clique no seu nome, no canto superior direito, e depois em "Sair".

## Usar no tablet

O sistema é preparado para funcionar como aplicativo instalável em tablets (PWA) — essa instalação fica disponível a partir da Fase 1, quando as telas de produção/expedição/visita técnica (as que mais usam tablet) entrarem no ar.
